# v0.5.9 桌面安装与本地数据迁移

- Windows 新增安装版 `RoleSchedule-Windows-x64-Setup.exe`，支持标准安装和覆盖更新。
- Windows 继续提供便携版，方便不想安装的用户使用。
- macOS 新增 `RoleSchedule-macOS.pkg` 安装包，同时保留 DMG 镜像版。
- Windows 和 macOS 设置中新增本地项目数据位置，可将游戏、角色、任务和完成记录迁移到指定文件夹。
- 数据迁移完成后会提示并自动重启应用；目标位置已有同名数据文件时不会覆盖。
- Windows 和 macOS 的应用内检查更新会优先下载对应平台的安装包。
- 正式发布流程固定产出 Windows 安装版、Windows 便携版、macOS PKG、macOS DMG 和 Android APK。
