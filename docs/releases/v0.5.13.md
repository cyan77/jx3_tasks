# 操作体验与入口图标

- 全部任务与日历切换页面后保留各自选择的筛选条件。
- 周期任务显示本周期进度和按游戏日切时间计算的下次刷新时间。
- 收集箱与今日任务新增快捷操作菜单；桌面任务、角色、游戏等支持右键菜单，长按仍用于多选。
- 手机底部导航始终显示入口名称，优化桌面侧栏与任务操作图标，并去除导航和新建按钮的阴影。
- 重新设计手机与桌面入口图标，桌面侧栏底部显示当前版本号。
- 日历页新增周视图与月视图，月视图改为紧凑日期点位，周视图支持较大的任务格展示。
- 日历默认进入周视图，并保留离开页面前选择的周/月视图与日期。
- 收集箱新建任务时可以直接分配角色，分配后自动移出收集箱。
- 首页角色信息、当前角色定位和日期标题展示进一步统一，手机端保持紧凑布局。
